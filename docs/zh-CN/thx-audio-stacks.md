4.2.41.2499 仅用于识别已有安装，暂无对应的基础安装包。4.2.37.1621 的全新安装和实机音效仍需验证。

每个现代条目记录原始下载链接、文件大小、SHA-256、数字签名，以及驱动文件和固定配置文件的校验值。Git 仓库只保存元数据；文件由 Razer 提供，或按授权作为目录的独立发行附件提供。

电脑还需要安装与硬件匹配的 Realtek 基础音频驱动；THX 安装包不包含该驱动。Razer 建议通过 [Windows 更新或系统恢复](https://mysupport.razer.com/app/answers/detail/a_id/3985)恢复音频驱动。rznb11 不能替代 rznb12。

旧版条目记录了 RZ09-0482、RZ09-0483 和 RZ09-0484 对应的 Realtek 编解码器硬件 ID 和基础驱动包，以及四个已签名的 Windows 11 THX 2.6.5 组件包：服务、HSA、配置和 APO。SCU 工具内置了型号识别规则和 THX SpeakerPath 调音数据：子系统编号 `2020` 对应 PI490，`3006` 对应 SO690，`3007` 对应 KI890。工具会拒绝使用通用备用配置。

已找到并验证 `THXHDAudio.inf` 扩展的签名。它包含三个型号的准确硬件 ID，以及 `THXAPO`、`THXSVC`、`THXHSA` 和 `THXSCU` 四个组件的关联规则，使用 AVX2 APO 和按子系统选择配置的 SCU。配置文件路径为 `%ProgramData%\THX\thx_spatial.conf.json`。

Git 副本使用 LF 换行，无法通过原始驱动签名目录的校验。仅将换行还原为 CRLF 后，29,311 字节的文件便与签名目录中的校验值完全一致，驱动指令没有改动。仍需查明对应型号的完整 CompositeFX 音效处理链配置、安装顺序，以及重新扫描设备和重启的要求，因此暂不提供全新安装。

这些条目不表示可以覆盖或修复已有的 THX 驱动。安装程序返回成功也不能证明所有组件都已正确安装，OpenBlade 仍需独立检查驱动包、签名目录、配置和运行中的服务。用户设置和预设不属于固定配置校验的范围。

完整的来源证据和安装限制见[英文说明](../thx-audio-stacks.md)。新增型号时，必须更新[适用性记录](../../catalog/applicability.json)。
