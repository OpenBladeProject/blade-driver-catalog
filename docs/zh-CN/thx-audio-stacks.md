# THX 音频驱动组件

目录分别记录 rznb11 和 rznb12 两套 THX 驱动。OpenBlade 必须根据准确的笔记本型号和音频硬件 ID 选择驱动，不能因为它们共用控制 DLL 就混用。

| 型号 | 驱动组件 | Razer 下载来源 |
| --- | --- | --- |
| RZ09-0528、RZ09-0530 | [rznb11 4.2.29.1159](../../components/thx-rznb11/4.2.29.1159/stack.json)，配置版本 4.2.37.1845 | 可下载基础 APO 安装程序及两个配置更新程序。全新安装仍处于实验阶段，尚未在实机上验证。 |
| RZ09-0581 | [rznb12 4.2.41.2499](../../components/thx-rznb12/4.2.41.2499/stack.json)，配置版本 4.2.37.1846 | 已核查的清单只提供配置更新程序，没有基础 APO 安装程序，因此目前无法完整安装。 |

每个条目记录原始下载链接、文件大小、SHA-256、数字签名，以及驱动文件和固定配置文件的校验值。目录只保存元数据，文件由 Razer 直接提供。

电脑还需要安装与硬件匹配的 Realtek 基础音频驱动；THX 安装包不包含该驱动。Razer 建议通过 [Windows 更新或系统恢复](https://mysupport.razer.com/app/answers/detail/a_id/3985)恢复音频驱动。rznb11 不能替代 rznb12。

这些条目不表示可以覆盖或修复已有的 THX 驱动。安装程序返回成功也不能证明所有组件都已正确安装，OpenBlade 仍需独立检查驱动包、签名目录、配置和运行中的服务。用户设置和预设不属于固定配置校验的范围。

完整的来源证据和安装限制见[英文说明](../thx-audio-stacks.md)。新增型号时，必须更新[适用性记录](../../catalog/applicability.json)。
