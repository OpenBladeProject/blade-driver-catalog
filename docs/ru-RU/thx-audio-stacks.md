# Драйверы THX

В каталоге отдельно описаны два современных семейства THX и свидетельства о старом поколении 2.6.5. OpenBlade должен выбирать набор по точной модели ноутбука и аппаратному идентификатору аудиоустройства. Общий клиент или универсальные программные компоненты не доказывают применимость полного набора.

Версия 4.2.41.2499 используется только для проверки уже установленного стека: соответствующего базового установщика пока нет. Чистая установка 4.2.37.1621 и работа звука на реальном устройстве ещё не проверены.

Каждая современная запись содержит исходные ссылки, размеры файлов, SHA-256, сведения о цифровой подписи и контрольные суммы файлов драйверов и неизменяемой конфигурации. В Git хранятся только метаданные; файлы загружаются с серверов Razer или из отдельно опубликованных вложений к выпуску каталога, на которые получено разрешение.

Эти контрольные суммы проверяют загружаемые файлы и результаты установки; они не задают список разрешённых сборок уже установленного драйвера. В [PR #819](https://github.com/OpenBladeProject/openblade-core/pull/819) основной проект проверяет точную модель, устройство, привязку пакета и службы, доверие Windows к подписи и ответы API. Совместимое обновление драйвера не требует новых хешей в каталоге или новой версии OpenBlade. Отпечатки содержимого позволяют обнаружить замену файлов и сбросить устаревшие результаты проверки. Проверка точных файлов при загрузке и установке сохраняется.

В черновом [PR #819](https://github.com/OpenBladeProject/openblade-core/pull/819) для основного проекта реализован этап установки базовых аудиодрайверов для этих трёх моделей. RZ09-0528 и RZ09-0530 используют соответствующий пакет Realtek HDA, а RZ09-0581 — Intel SST и встроенные драйверы Windows SDCA. После проверки точной модели и подлинности пакетов этот код может установить указанные в каталоге пакеты Realtek или Intel. Встроенные драйверы SDCA должны быть доступны в Windows и пройти проверку подлинности. Сами пакеты THX этих базовых драйверов не содержат.

Официальные источники и требования к проверке приведены в [описании базовых аудиодрайверов](../thx-base-audio-prerequisites.md). Изменения ещё не включены в основную ветку и не опубликованы; чистая установка в системе без установленного Synapse, поведение после перезагрузки и фактический вывод звука на реальном устройстве ещё не проверены. Razer также описывает восстановление аудиодрайверов через [Центр обновления Windows или восстановление системы](https://mysupport.razer.com/app/answers/detail/a_id/3985). Нельзя использовать rznb11 вместо rznb12.

Для старого поколения указаны точные аппаратные идентификаторы кодеков Realtek и базовые пакеты для RZ09-0482, RZ09-0483 и RZ09-0484, а также четыре подписанных пакета THX 2.6.5 для Windows 11: служба, HSA, конфигурация и APO. Подписанная утилита SCU содержит правила выбора модели и данные настройки THX SpeakerPath: идентификатор подсистемы `2020` соответствует PI490, `3006` — SO690, а `3007` — KI890. Утилита отклоняет универсальную резервную конфигурацию.

Найдено расширение `THXHDAudio.inf`, подлинность которого проверена по подписанному каталогу драйвера. Оно содержит точные аппаратные идентификаторы трёх моделей и правила привязки компонентов `THXAPO`, `THXSVC`, `THXHSA` и `THXSCU`: обычный APO AVX2 и выбор конфигурации SCU по идентификатору подсистемы. Путь конфигурации — `%ProgramData%\THX\thx_spatial.conf.json`.

В Git переводы строк INF заменены на LF, поэтому эта копия не проходит проверку по исходному подписанному каталогу. После восстановления исходных переводов строк CRLF файл размером 29 311 байт точно соответствует хешу в каталоге; инструкции драйвера не изменены. Ещё нужны настройки всей цепочки CompositeFX для этих моделей, порядок установки и требования к повторному обнаружению устройств и перезапуску. Чистая установка пока недоступна.

Эти записи не разрешают заменять или исправлять уже установленный набор THX. Успешный код завершения установщика не подтверждает установку всех компонентов: OpenBlade должен отдельно проверить пакеты, каталоги подписей, конфигурацию и работающую службу. Пользовательские настройки и пресеты не входят в контрольные суммы неизменяемой конфигурации.

Подробные сведения об источниках и ограничениях приведены в [английском описании](../thx-audio-stacks.md). При добавлении модели необходимо обновить [учёт применимости](../../catalog/applicability.json).
