# Драйверы THX

В каталоге отдельно описаны два набора драйверов THX: rznb11 и rznb12. OpenBlade должен выбирать набор по точной модели ноутбука и аппаратному идентификатору аудиоустройства. Общая управляющая DLL не делает драйверы взаимозаменяемыми.

| Модели | Набор драйверов | Загрузка с серверов Razer |
| --- | --- | --- |
| RZ09-0528, RZ09-0530 | [rznb11 4.2.29.1159](../../components/thx-rznb11/4.2.29.1159/stack.json), конфигурация 4.2.37.1845 | Доступны основной установщик APO и две программы обновления конфигурации. Чистая установка остаётся экспериментальной и ещё не проверена на реальном устройстве. |
| RZ09-0581 | [rznb12 4.2.41.2499](../../components/thx-rznb12/4.2.41.2499/stack.json), конфигурация 4.2.37.1846 | Проверенный манифест содержит только обновления конфигурации. Основного установщика APO нет, поэтому полная установка пока недоступна. |

Каждая запись содержит исходные ссылки, размеры файлов, SHA-256, сведения о цифровой подписи и контрольные суммы файлов драйверов и неизменяемой конфигурации. Каталог хранит только метаданные; сами файлы загружаются с серверов Razer.

На компьютере уже должен быть установлен подходящий базовый аудиодрайвер Realtek: пакет THX его не содержит. Razer рекомендует восстановить аудиодрайвер через [Центр обновления Windows или восстановление системы](https://mysupport.razer.com/app/answers/detail/a_id/3985). Нельзя использовать rznb11 вместо rznb12.

Эти записи не разрешают заменять или исправлять уже установленный набор THX. Успешный код завершения установщика не подтверждает установку всех компонентов: OpenBlade должен отдельно проверить пакеты, каталоги подписей, конфигурацию и работающую службу. Пользовательские настройки и пресеты не входят в контрольные суммы неизменяемой конфигурации.

Подробные сведения об источниках и ограничениях приведены в [английском описании](../thx-audio-stacks.md). При добавлении модели необходимо обновить [учёт применимости](../../catalog/applicability.json).
