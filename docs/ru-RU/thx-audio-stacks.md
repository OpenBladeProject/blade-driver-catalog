# Драйверы THX

В каталоге отдельно описаны два современных семейства THX и свидетельства о старом поколении 2.6.5. OpenBlade должен выбирать набор по точной модели ноутбука и аппаратному идентификатору аудиоустройства. Общий клиент или универсальные программные компоненты не доказывают применимость полного набора.

Версия 4.2.41.2499 используется только для проверки уже установленного стека: соответствующего базового установщика пока нет. Чистая установка 4.2.37.1621 и работа звука на реальном устройстве ещё не проверены.

Каждая современная запись содержит исходные ссылки, размеры файлов, SHA-256, сведения о цифровой подписи и контрольные суммы файлов драйверов и неизменяемой конфигурации. В Git хранятся только метаданные; файлы загружаются с серверов Razer или из отдельно опубликованных вложений к выпуску каталога, на которые получено разрешение.

На компьютере уже должен быть установлен подходящий базовый аудиодрайвер Realtek: пакет THX его не содержит. Razer рекомендует восстановить аудиодрайвер через [Центр обновления Windows или восстановление системы](https://mysupport.razer.com/app/answers/detail/a_id/3985). Нельзя использовать rznb11 вместо rznb12.

Для старого поколения указаны точные аппаратные идентификаторы кодеков Realtek и базовые пакеты для RZ09-0482, RZ09-0483 и RZ09-0484, а также четыре подписанных пакета THX 2.6.5 для Windows 11: служба, HSA, конфигурация и APO. Подписанная утилита SCU содержит правила выбора модели и данные настройки THX SpeakerPath: идентификатор подсистемы `2020` соответствует PI490, `3006` — SO690, а `3007` — KI890. Утилита отклоняет универсальную резервную конфигурацию. Пока не выяснено, как компоненты `SWC\\VEN_THX` связываются с аудиокодеком каждой модели и как FX/APO подключаются к звуковым выходам. Поэтому эти компоненты ещё нельзя считать полным набором для установки.

Эти записи не разрешают заменять или исправлять уже установленный набор THX. Успешный код завершения установщика не подтверждает установку всех компонентов: OpenBlade должен отдельно проверить пакеты, каталоги подписей, конфигурацию и работающую службу. Пользовательские настройки и пресеты не входят в контрольные суммы неизменяемой конфигурации.

Подробные сведения об источниках и ограничениях приведены в [английском описании](../thx-audio-stacks.md). При добавлении модели необходимо обновить [учёт применимости](../../catalog/applicability.json).
