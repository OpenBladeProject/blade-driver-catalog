# Компоненты от производителя

[English](../upstream-components.md) | [简体中文](../zh-CN/upstream-components.md) | Русский

Каталог может описывать компонент, который OpenBlade получает напрямую с
сайта производителя, не выдавая его за пакет Driver Store и не публикуя
проприетарный файл. Для таких записей используется отдельная схема
[`OpenBlade.RazerUpstreamComponentCatalogEntry`](../../schemas/upstream-component.schema.json).

## Компонент THX V4 Native

В [записи THX V4 Native 1.1.1.0](../../components/thx-v4-native/1.1.1.0/component.json)
указаны точный адрес производителя, размер файла, SHA-256, подписант
Authenticode и три профиля Razer, в текущих манифестах Synapse которых указан
тот же файл. Каталог не содержит и не публикует DLL.

OpenBlade может предложить прямую загрузку с сайта производителя. Перед
использованием файла программа должна проверить указанные SHA-256 и подпись
Authenticode. Загружается только отдельная DLL; APO и другие компоненты THX не
устанавливаются.

Эта запись служит исходными данными, а не подтверждением установки или
совместимости. За проверку точной модели, выбор места назначения, проверку во
время работы и восстановление отвечает OpenBlade core. Связанная работа по
обнаружению компонента описана в
[задаче OpenBlade #808](https://github.com/OpenBladeProject/openblade-core/issues/808).

## Проверка всех поддерживаемых моделей

[`catalog/applicability.json`](../../catalog/applicability.json) фиксирует все
семь моделей OpenBlade и решение по каждой записи каталога для каждой модели.
`Applicable` означает наличие подтверждающего источника; `NotEstablished` —
недостаточность данных, а не несовместимость. Эти статусы не разрешают установку
или управление устройством.

Проверка от 2026-10-19 подтвердила THX V4 Native 1.1.1.0 для RZ09-0530,
RZ09-0528 и RZ09-0581. В проверенных манифестах RZ09-0328, RZ09-0482,
RZ09-0483 и RZ09-0484 ресурс THX native отсутствует. Универсальность не установлена.
Оба комплекта драйверов ограничены своим PID: совпадающие файлы RzCommon и
общий дочерний идентификатор не делают весь комплект универсальным.

При добавлении или изменении модели в core проверьте все драйверы и компоненты,
обновите закреплённую ревизию core, список моделей и все решения в реестре,
а затем `applicableProfiles` и закреплённую копию реестра в тестах core.
Запустите тесты обоих репозиториев. Новая запись каталога также требует решения
для каждой модели. Проверка core должна завершаться ошибкой до обновления
покрытия; тесты каталога отклоняют пропущенные решения и расхождения применимости.

## Драйверы THX

В [каталоге драйверов THX](thx-audio-stacks.md) рассмотрены все семь поддерживаемых моделей: точные пакеты rznb11 и rznb12, заблокированные кандидаты старого поколения 2.6.5 для трёх моделей THX 2023 года и RZ09-0328 только с Dolby. Кандидаты 2.6.5 нельзя устанавливать без точного OEM-перечисления дочерних компонентов и настройки модели; для rznb12 также по-прежнему отсутствует основной установщик.
