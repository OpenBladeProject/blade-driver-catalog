# Компоненты от производителя

[English](../upstream-components.md) | [简体中文](../zh-CN/upstream-components.md) | Русский

Каталог может описывать компонент, который OpenBlade получает напрямую с
сайта производителя, не выдавая его за пакет Driver Store и не публикуя
проприетарный файл. Для таких записей используется отдельная схема
[`OpenBlade.RazerUpstreamComponentCatalogEntry`](../../schemas/upstream-component.schema.json).

## Компонент THX V4 Native

В [записи THX V4 Native 1.1.1.0](../../components/thx-v4-native/1.1.1.0/component.json)
указаны точный адрес производителя, размер файла, SHA-256, подписант
Authenticode и три профиля Razer, в текущих манифестах Synapse которых указан
тот же файл. Каталог не содержит и не публикует DLL.

OpenBlade может предложить прямую загрузку с сайта производителя. Перед
использованием файла программа должна проверить указанные SHA-256 и подпись
Authenticode. Загружается только отдельная DLL; APO и другие компоненты THX не
устанавливаются.

Эта запись служит исходными данными, а не подтверждением установки или
совместимости. За проверку точной модели, выбор места назначения, проверку во
время работы и восстановление отвечает OpenBlade core. Связанная работа по
обнаружению компонента описана в
[задаче OpenBlade #808](https://github.com/OpenBladeProject/openblade-core/issues/808).
