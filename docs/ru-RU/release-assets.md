<a id="what-belongs-in-git"></a>
## Что хранится в Git

В Git хранятся только метаданные и инструменты. Файлы INF, CAT, SYS, PNF, ZIP
и другие проприетарные файлы пакетов исключены правилами репозитория, и их
нельзя добавлять в коммиты. Полные идентификаторы устройств и локальные
инвентаризационные данные также должны оставаться вне репозитория.

Закрытый архив доказательств, созданный во время сбора, ни при каких условиях
не должен публиковаться среди файлов выпуска. Он содержит полные идентификаторы
устройств, локальные инвентаризационные данные и другие сведения о конкретном
компьютере. Закрытый процесс сбора и поля, разрешённые в очищенном манифесте,
описаны в [руководстве по экспорту](exporting.md).

<a id="publishing-a-package-archive"></a>
## Публикация архива пакетов

Перед публикацией архива прочитайте
[THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md). Письменное разрешение
должно охватывать конкретные файлы, версии, аудиторию и способ распространения.

Архив, содержащий только пакеты, можно приложить к выпуску лишь после проверки
экспортера для конкретной модели и манифеста каталога. Экспортер должен
копировать только допущенные файлы, сверять их зафиксированные хеши и данные
подписантов, удалять закрытые инвентаризационные данные и локальные псевдонимы,
а также включать требуемое уведомление о сторонних материалах.

Владелец проекта сообщает о письменном разрешении Razer US Ltd на распространение
файлов обоих предварительных выпусков для указанной аудитории и указанным способом.
Каталог не утверждает, что документ с этим разрешением прошёл независимую
проверку. Лицензия Apache-2.0 распространяется только на оригинальное содержимое
репозитория и не предоставляет прав на содержимое пакетов Razer или проприетарные
файлы выпуска.

<a id="prerelease-records"></a>
## Записи предварительных выпусков

Проверенные записи для [Blade 16 2026 года](../../releases/rz09-0581-02e0-1.0.0.78-1.0.0.76.json)
и [Blade 16 2025 года](../../releases/rz09-0528-02c6-1.0.0.78-1.0.0.76.json)
связывают каждый манифест каталога с соответствующим файлом выпуска. В обеих
записях указаны ревизия экспортера и хеш скрипта.

Любое изменение аудитории выпуска требует отдельного решения о распространении
в рамках зафиксированного разрешения.

Зафиксированный коммит экспортера пакета 2026 года доступен из ветки `main`
ядра через [PR #163 OpenBlade core](https://github.com/OpenBladeProject/openblade-core/pull/163),
объединённый 15 августа 2026 года. Git-объект и SHA-256 скрипта совпадают с
записью. В записи сохранена исходная ревизия экспорта со статусом
`MergedCommit`. Для пакета 2025 года используется экспортер конкретной модели,
добавленный в [PR #15 каталога](https://github.com/OpenBladeProject/blade-driver-catalog/pull/15).

<a id="openblade-repository-responsibilities"></a>
## Ответственность репозиториев OpenBlade

- [`openblade-core`](https://github.com/OpenBladeProject/openblade-core/blob/main/README.ru-RU.md) отвечает за
  проверки допуска при работе, проверки точной модели устройства, резервные
  способы управления и проверенную политику установки.
- [`synapse-observer`](https://github.com/OpenBladeProject/synapse-observer/blob/main/README.ru-RU.md) собирает
  сведения об устройстве и изменениях настроек Synapse для новых запросов на поддержку.
  Закрытый устаревший репозиторий `openblade-captures` хранит прежние
  данные протоколов и тестовые материалы.
- Этот репозиторий отвечает за инвентаризацию пакетов драйверов, инструкции по
  экспорту без изменения системы, очищенные манифесты и файлы выпуска, охваченные
  зафиксированным разрешением.

До того как OpenBlade core примет утверждение о работе или установке, рецензент
должен подтвердить топологию пакетов. Физическая проверка, перезапуск хоста
драйвера, перезагрузка, сон, чистая установка, откат и допуск в рабочую среду
остаются отдельными проверками.
